# Tiles

`ruins.png` is original art for this project, painted by `Tools/TileForge/ruins_atlas.py` (procedural pixel
art, so no third-party license applies). To change it, edit the script and run:

    python Tools/TileForge/ruins_atlas.py

The layout is 8×5 cells of 16×16 art pixels at 4× (64 px cells). `WorldMeshBuilder` documents which cell
is used where.
