# Battle effects

**Super Pixel Effects Gigapack (Free Version) v3.1.0 - Will Tice / unTied Games**
https://untiedgames.itch.io/super-pixel-effects-gigapack

License summary (full text: http://untiedgames.com/files/license.txt): bundling the effects in a game is fine, commercial or not,
with attribution in the credits. Do **not** publicly redistribute the pack's files on their own (for example in a public
repository or an asset store), and do not use them as AI training material.

Each effect is `<name>.png` (the pack's spritesheet) plus `<name>.txt` (one line per frame: `frameNNNN x y w h`, y from the top),
read by `FxLibrary`. Which effect plays when is set in `BattleFx` (Scripts/View/FxLibrary.cs). The full pack zip is outside the repo.
