# REVERSE SHELL — Chapter One script
#
# Paste text in from the game bible or any document. How it works:
#   [key]                 starts a block (the game asks for blocks by key; keep the keys as they are)
#   Speaker | text        one dialogue box spoken by Speaker
#   text                  one box of narration (no speaker)
#   Thought | text        the protagonist's inner voice (no name plate, soft blue-grey). The protagonist barely speaks
#                         out loud: keep their lines as Thoughts and their answers short, so scenes read the same
#                         whichever ally leads the party.
#   # anything            a comment, ignored
# A whole paragraph can go on one line: lines too long for the box are split into several boxes automatically.
# {name} is replaced by the protagonist's name.
# Markup: {p} short pause, {p=0.8} pause 0.8 s, {slow}...{/slow}, {fast}...{/slow}, {wave}...{/wave},
#         {shake}...{/shake}, colours {gold} {red} {gray} {green} {c=#RRGGBB} ... {/c}
# All of this text is a first draft (bible §13). Edit freely; the game reads it fresh each run.
