# REVERSE SHELL — everything the game says outside Chapter One's script
#
# Same format as Chapter1.txt:
#   [key]                 starts a block (the game asks for blocks by key; keep the keys as they are)
#   Speaker | text        one dialogue box spoken by Speaker
#   text                  one box of narration (no speaker)
#   # anything            a comment, ignored
# {name} is the protagonist's name. Some blocks take other fill-ins, listed above them (e.g. {item}).
# Markup: {p} pause, {p=0.8}, {slow}...{/slow}, {fast}...{/fast}, {wave}...{/wave}, {shake}...{/shake},
#         colours {gold} {red} {gray} {green} {cyan} {c=#RRGGBB} ... {/c}
